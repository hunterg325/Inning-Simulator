## Inning Simulator

#### Getting started

#### Step 1
Install node.js. It can be downloaded from here: [nodejs.org](https://nodejs.org/en/)
(I'm running the latest LTS version v10.16.0)

#### Step 2
`git clone https://github.com/hunterg325/Inning-Simulator.git`

#### Step 3
`cd Inning-Simulator && npm install`

#### Step 4
`node main.js 1b,2b,3b,k,k`
